# 簡易時系列分析ツール (Time-Series STL Analysis Tool)

ExcelやCSVの時系列データを取り込み、ブラウザ上でSTL分解（季節・トレンド分離）、トレンド変化点検出、および残差のCUSUM異常検知を完全ローカルで実行できるWebアプリケーションです。

---

## 🚀 ローカルサーバの起動方法

ブラウザのES Modules（`import/export`）制限を回避し、キャッシュの影響を受けずに確認・動作検証を行うための簡易HTTPサーバスクリプトを用意しています（外部ライブラリ不要・Python 3標準ライブラリのみで動作）。

### 起動コマンド

```bash
# どちらか一方のコマンドを実行してください
./serve.sh
# または
python3 serve.py
```

* 起動すると自動的に `http://localhost:8000/index.html` がブラウザで開きます。
* 8000番ポートが使用中の場合は、空いているポート番号（8001〜）を自動選択します。
* 開発・検証用としてブラウザキャッシュ無効化ヘッダー（`Cache-Control: no-cache`）が付与されます。
* 終了するにはターミナルで `Ctrl + C` を押してください。

---

## ✨ 主な機能

* **データ入力:** Excel (.xlsx, .xls) / CSV ファイルのドラッグ＆ドロップ、またはテキスト（TSV/CSV）の直接貼り付け
* **STL分解:** 加法/乗法モデルの自動判定、期間内固定/経年変化の季節性抽出
* **トレンド変化点検出:** トレンド成分から変曲点・ピーク（天井）・ボトム（底打ち）・急加速を自動検出
* **残差CUSUM分析:** 残差の持続的な上振れ・下振れドリフトを累積和法で検知
* **図への付加/非付加トグル:** グラフ上のチェックボックスで変化点やCUSUM異常の表示/非表示を瞬時に切替
* **エクスポート:** グラフのPNG画像保存、分解結果や診断フラグを含むCSV出力

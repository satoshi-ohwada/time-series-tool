# 簡易時系列分析ツール (Time-Series STL Analysis Tool)

ExcelやCSVの時系列データを取り込み、ブラウザ上で**STL分解（季節・トレンド分離）**、**トレンド変化点検出**、および**残差のCUSUM異常検知**を完全ローカルで実行できる高機能・軽量なWebアプリケーションです。

外部サーバーへデータを送信しないため、機密データや社内データも安全に解析できます。

## ✨ 特長

1. **完全クライアントサイド実行 (通信ゼロ・高セキュリティ)**
   * すべてのデータ解析・統計計算・グラフ描画はお使いのブラウザ（JavaScript）内で完結します。
   * 外部サーバーへのデータアップロードが一切ないため、漏洩リスクがなく安全・高速です。
2. **日本のビジネス実務に即したデータ対応**
   * 日本のExcelから出力された **Shift_JIS (CP932)** および **UTF-8** のCSVを自動判別してデコード。
   * `1,250` などの3桁カンマ区切り数値列の自動認識、日付列の自動認識、欠損値の自動線形補間を搭載。
3. **多角的な時系列診断**
   * 単なる分解にとどまらず、トレンドの曲率から**「いつ成長が加速/鈍化したか」「いつ底打ち/天井を打ったか」**を特定。
   * 残差の累積和（CUSUM）により、突発的な単発ノイズと**「政策や外生ショックによる持続的シフト」**を区別して検知。

## 🚀 クイックスタート (ローカル起動)

モダンブラウザのセキュリティ仕様（ES Modulesのローカルファイル制限）を回避し、キャッシュの影響を受けずに確認できる簡易HTTPサーバスクリプトを同梱しています（Python 3標準ライブラリのみで動作、追加インストール不要）。

```bash
# ターミナルで以下のいずれかを実行してください
./serve.sh
# または
python3 serve.py
```

* 実行すると自動的にブラウザで `http://localhost:8000/index.html` が開きます。
* 8000番ポートが使用中の場合は、自動的に空きポート（8001〜）を検出して起動します。
* 開発・確認用としてブラウザキャッシュ無効化ヘッダー（`no-cache`）が付与されます。
* 終了するにはターミナルで `Ctrl + C` を押してください。

## 🔍 主要機能一覧

### 1. データ取り込み & 前処理
* **ファイル読み込み:** Excel (`.xlsx`, `.xls`) および CSV ファイルのドラッグ＆ドロップ、またはファイル選択。
* **直接テキスト貼り付け:** スプレッドシート等からコピーしたTSV/CSVテキストを貼り付けて解析可能。
* **列の自動判定:** ヘッダーと先頭行から「時間軸（日付・年月等）」と「数値の変数列」を自動検出。
* **周期の自動検出:** 自己相関関数（ACF）を計算し、データに内在する主要な周期（月次: 12、四半期: 4、週次: 7等）を自動推定。
* **欠損値補間:** 日付の抜け漏れを等間隔時系列として検出し、線形補間を実行（設定でON/OFF可能）。
* **サンプルデータ機能:** 「デモデータを読み込む」ボタンで、時系列解析の標準データセット（英国交通事故死傷者数）を即座に試用可能。

### 2. STL分解 (季節・トレンド分離)
LOESS（局所多項式回帰）を用いた Cleveland et al. (1990) に準拠した頑健な時系列分解アルゴリズムを実装しています。
* **加法モデル (Additive):** $Observed = Trend + Seasonal + Residual$
* **乗法モデル (Multiplicative):** $Observed = Trend \times Seasonal \times Residual$
* **自動モデル判定:** 加法・乗法の両方を内部計算し、残差のばらつきが小さく綺麗に分解できる側を自動採択（手動固定も可能）。
* **季節性モード切替:**
  * `固定 (Periodic)`: 全期間で一定の季節パターンを抽出。
  * `柔軟 (Flexible)`: 年ごとの気候変動や流行推移に伴う「季節パターンの緩やかな変化」に追従。

### 3. トレンド主要変化点の自動検出
平滑化されたトレンド曲線の1次微分（傾き）および2次微分（曲率・加速度）を解析し、構造的な転換点を自動検出します。
* **検出される変化点タイプ:**
  * ⛰️ **ピーク (天井):** 上昇トレンドから下降トレンドへの反転。
  * 🏜️ **ボトム (底打ち):** 下降トレンドから上昇トレンドへの反転。
  * 📈 **上昇加速・反転:** 上昇ペースの急激な加速、または下落の下げ止まり。
  * 📉 **下降加速・成長鈍化:** 下降ペースの急加速、または成長ペースの失速。
* **重複抑制 (NMS):** 極大値・極小値の近傍で重複してピンが立たないようフィルタリング。
* **感度設定:** サイドバーで「低（最大3点）」「中（最大5点）」「高（最大8点）」を調整可能。
* **表示トグル:** グラフ上部の `[📍 変化点を表示]` チェックボックスで瞬時に表示/非表示を切替。

### 4. 残差CUSUM法による持続的異常シフト検知
残差系列（トレンドと季節性で説明しきれなかった成分）に対して、二面Tabular CUSUM（累積和法）を適用します。
* **目的:** 単発の外れ値（猛暑の1日など）ではなく、「政策変更」「法改正」「市場ショック」等による**持続的な水準の変化（偏留）**を検出。
* **モデル自動適合:**
  * 加法モデル残差: 基準値 $\mu_0 = 0.0$ からのズレを累積。
  * 乗法モデル残差: 基準値 $\mu_0 = 1.0$ からのズレを累積。
* **パラメータ設計:**
  * 許容参照値 $k = 0.5\sigma$（半標準偏差のシフトを検知）
  * 管理限界閾値 $h = 4.0\sigma$（感度に応じて $3.0\sigma \sim 5.0\sigma$ に可変）
* **表示トグル:** グラフ上部の `[⚠️ CUSUM異常を表示]` チェックボックスで表示切替（**デフォルトはOFF**で邪魔になりません）。

### 5. インタラクティブなグラフ可視化
Plotly.js をベースにした操作性の高いグラフ描画：
* **豊富な表示モード:**
  1. `元データ と トレンド` (大局傾向の把握に最適)
  2. `元データ と 周期調整済データ` (季節性を除去した実態把握)
  3. `4成分分解 (Subplots)` (元データ・トレンド・周期・残差の上下4段並列表示)
  4. `元データのみ` / `トレンドのみ` / `周期変動のみ` / `残差のみ`
  5. `残差 CUSUM 管理図` ($C^+, -C^-$ の推移と管理限界線 $\pm h$ を可視化)
* **背景モード切替:**
  * `ダーク (画面用)` / `白 (資料印刷用)` / `透明 (スライド埋め込み用)`
* **ワンクリック画像保存:** `[🖼️ グラフ画像を保存 (PNG)]` ボタンで高解像度画像を即座にダウンロード。

### 6. 結果テーブル・表形式データ編集・エクスポート
* **📋 元データ入力・編集モード:** 取り込んだデータをブラウザ上の表で直接編集可能（セル修正・行追加・行削除）。
* **📈 STL分解結果表モード:** 各時点の実測値、トレンド値、周期変動値、残差、周期調整済データを一覧表示。
  * 検出された変化点（📍）やCUSUM異常（⚠️）のバッジを表示。
* **💡 分析のヒント（自動解説）:**
  * 自動選択されたモデルの解説、期間全体のトレンド変動幅（上昇/下降量）、周期変動の最大振幅、検出された変化点一覧、CUSUM診断コメントを日本語で自動生成。
* **CSVエクスポート:**
  * `選択中の変数をCSV保存`: 現在表示している変数の分解結果と診断フラグを出力。
  * `全変数を一括CSV保存`: 複数列のデータをまとめて出力。

## ⚙️ 技術スタック & パフォーマンス

* **フロントエンド:** Vanilla JavaScript (ES2020+), HTML5, CSS3
* **グラフエンジン:** Plotly.js 2.x
* **データ処理:** SheetJS (xlsx)
* **パフォーマンス特性:**
  * CUSUM法・変化点検出は $O(N)$ の1パス処理のため、1,000点でも **1〜3ミリ秒** で完了。
  * 一般的な月次データ（100〜300件）や年次データ（100件超）のSTL分解処理は **0.01〜0.03秒** 程度で即座に完了し、極めて快適に動作します。
